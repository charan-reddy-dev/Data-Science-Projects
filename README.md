# 📊 Data Science & Product Decisions Portfolio

Welcome to my Data Science Portfolio. This repository hosts advanced end-to-end analytics and predictive projects built to drive business growth, optimize product features, and translate statistical findings into actionable business ROI.

---

## 🚀 Projects Included

### 1. [AeroTest: Enterprise A/B Testing & Statistical Engine](ab-testing-platform)
* **Live Demo**: [https://charanloyal.github.io/Data-Science-Projects/ab-testing-platform/](https://charanloyal.github.io/Data-Science-Projects/ab-testing-platform/)
* **Core Jupyter Notebook**: [ab_testing_analysis.ipynb](ab-testing-platform/notebooks/ab_testing_analysis.ipynb)
* **Domain**: Product Analytics, Growth Data Science, Statistics.
* **Key Components**:
  * Pre-experiment sample size calculator (power analysis).
  * Hypothesis testing (Two-Proportions Z-Test).
  * Sample Ratio Mismatch (SRM) Chi-Square Goodness-of-Fit detector to prevent data tracking bias.
  * Payback duration and visual business ROI projections.

### 2. [ChurnIntel: Predictive Customer Intelligence & GenAI SQL Copilot](churn-predictive-agent)
* **Live Demo**: [https://charanloyal.github.io/Data-Science-Projects/churn-predictive-agent/](https://charanloyal.github.io/Data-Science-Projects/churn-predictive-agent/)
* **Core Jupyter Notebook**: [churn_modeling.ipynb](churn-predictive-agent/notebooks/churn_modeling.ipynb)
* **Domain**: Supervised Machine Learning, Classification, Conversational AI.
* **Key Components**:
  * Real-time customer churn probability classifier with weight contributions (SHAP-like explainability).
  * GenAI SQL Copilot simulating a conversational agent translating natural language questions into executable SQL queries.
  * Campaign ROI calculator modeling lifetime value (LTV) recovery and campaign incentive costs.
